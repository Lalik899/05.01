MASTER.HUB — это веб-приложение (онлайн-биржа микро-услуг и репетиторства), предназначенное для взаимодействия заказчиков и частных исполнителей в различных сферах (программирование, дизайн, репетиторство и др.).
Цель проекта: автоматизация процесса поиска специалистов, оформления заказов и проведения расчетов по принципу «безопасной сделки» (эскроу), при которой денежные средства заказчика резервируются системой и перечисляются исполнителю только после подтверждения выполнения работы.
Проект разработан в учебных целях; все финансовые расчеты производятся с использованием внутреннего демонстрационного баланса пользователей.
